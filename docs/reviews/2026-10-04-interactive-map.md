# Student-sublease street map — 2026-10-04

The search map previously positioned raster backgrounds by hand. It had single-pointer dragging, but no anchored wheel zoom, native pinch zoom or retained camera when changing views. The broad first page also opened at continental scale, and Los Angeles demonstration coordinates formed an artificial diagonal unrelated to the named neighbourhoods.

The search basemap now uses locally bundled, lazily imported Leaflet 1.9.4 with the existing `tile.openstreetmap.de` image provider. It supports native dragging/inertia, pointer-anchored wheel zoom, double-click and touch pinch. Reduced motion disables inertia. A zero-sized or hidden canvas defers initialization; view and sort changes with the same page membership preserve the map instance and manual camera. Positive-size resize updates and queued hidden commands are bounded and cleaned up with listeners, animation frames and the layer on unmount.

A mixed-city page initially focuses its most represented city, explicitly selected in the city control; no search results are removed. The count distinguishes visible pins from current-page results. City focus and the all-page fit control only change the camera. Prices remain monthly rent, and previews retain lease dates and date-bearing detail links. Positions are labelled neighbourhood approximations. Fixture points use the named public neighbourhoods; exact addresses and device geolocation are not introduced. Saved and detail maps retain their existing mechanisms and inherit safer shared geometry.

All listing text, cluster pickers, price buttons and links remain escaped React elements above an isolated basemap. No listing content enters Leaflet popup HTML. Price controls preserve 44px minimum heights; keyboard arrows/+/- work on the map region without intercepting control keys. Selected pins stay above the preview using its actual bounds, including short landscape canvases. Cluster selection moves focus into its selected preview, and Escape/close restores the opener or map region. Group membership is deterministic across sort permutations, while picker rows retain catalog order.

The projection handles fractional gesture zoom, finite viewport dimensions, Mercator latitude limits and dateline crossings. Tile operations require integer zoom/coordinates and bounded work. Invalid listing coordinates fall back to the named area; inherited object-property names cannot become coordinates. Configured image templates require credential-free HTTPS with a fixed origin, known placeholders and no fragments, control characters or backslashes. Public query keys remain supported. Zoom stays within2–18, city fitting within14. Leaflet uses no HTML popups, workers, external JavaScript or permission prompts. Authentication, private-route guards, CSP, API/socket isolation, upload and payment boundaries are unchanged.

Current visible tile errors remain visible even if adjacent tiles decoded. Explicit retry recreates the surface at the current camera; there is no automatic retry loop or replacement image that hides failed delivery. Attribution links to OpenStreetMap copyright. Demo account, chat, applications, publishing and payments remain closed.
