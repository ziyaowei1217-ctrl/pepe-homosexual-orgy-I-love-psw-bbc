# 中国线控行业单市场图设计

## 目标

将现有全球—中国—国产替代综合图收敛为中国单市场视角，用一张透明底图同时表达中国线控市场扩容、产品结构变化和线控制动国产替代趋势，可直接插入 PowerPoint。

## 核心结论

2020–2030E 年中国线控市场保持快速增长，线控制动、线控悬架等细分市场同步扩容，同时国产线控制动销量与国产化率持续提升。

## 数据范围

- 主图：2020–2030E 中国线控解决方案市场规模。
- 主图结构：线控转向、线控制动、线控悬架、运动控制器四类产品。
- 补充带：2024–2030E 国产线控制动销量与国产化率。
- 删除：全球市场、“其他地区”、中国占全球比例及所有全球 CAGR 标注。
- 保留全部原始年度观测，不抽样、不删年。

## 版式

- 单一坐标系中的上下递进结构。
- 上部为四类产品堆叠柱，柱顶标中国市场总规模。
- 仅保留中国市场 2020–2024 和 2024–2030E 两段 CAGR。
- 下部为不与主轴直接比较的国产替代趋势带，显示销量、国产化率及全部年度数值。
- 用 2024/2025E 分界虚线标识预测期，不使用大面积预测底色。

## 视觉与导出

- 透明画布，无白色背景块。
- 保留必要网格、图例、单位、预测标识和口径说明。
- 输出透明 PNG 供直接插入 PowerPoint；输出 SVG 作为优先矢量版本。
- 采用 16:9 页面友好的宽幅比例，文字在常规 PPT 页面中保持可读。

## 验收标准

- 图中不出现任何全球或“其他地区”数据。
- 中国 2020–2030E 十一个年度点和国产替代 2024–2030E 七个年度点完整。
- SVG 保留可编辑文字；PNG 确认存在透明像素。
- 图例、数值和批注无明显遮挡或裁切。
