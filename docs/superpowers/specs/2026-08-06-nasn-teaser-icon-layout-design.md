# NASN A4 Teaser 图标与字号优化设计

## 目标

在不修改文案、数据、蓝金配色和 A4 纵向模板的前提下，把第 2 页的 8 个蓝金图标迁移到第 1 页，提升信息分区辨识度，同时修正字号层级、图片大小、对齐、边距和越界问题。

## 页面范围

- 第 1 页：正式 Teaser，执行全部版式优化。
- 第 2 页：保留为图标素材备份页，不改变内容。
- 输出为新文件，保留原文件不覆盖。

## 图标映射

### 行业概览

利用图表左侧现有空白区放置两枚较大的行业语义图标：

- 工厂与盾牌：制造能力、行业属性与安全要求。
- 全球网络：行业扩容、市场覆盖与国产替代趋势。

两枚图标保持足够留白，不遮挡图表、标题条或页面边界。

### 投资亮点

用第 2 页图标替换六个投资亮点卡片右侧现有大小不一、部分越界的小图，映射如下：

1. 客户粘性：团队与奖杯。
2. 智能驾驶运动控制专家：增长路径与机械臂。
3. 研发能力与技术积累：研发清单与认证徽章。
4. 模块化技术平台：整车底盘平台。
5. 技术积淀与成果转化：车、机器人与无人机网络。
6. 创新解决方案组合：解决方案手册与产品模块。

六枚图标统一视觉高度、右边距和垂直中心线，不侵入标题、指标或说明文字。

## 字号与间距

- 保持现有字体家族、颜色和字重。
- 适度放大章节标题、投资亮点标题和当前小于约 7 pt 的说明文字。
- 优先通过减少文本框内边距、调整文本框宽度和图片占位解决拥挤，不修改文案，也不让单行标题换行。
- 保持关键数据字号大于说明文字，并统一同级文字的字号。

## 质量标准

- 第 1 页无文字溢出、异常换行、图标遮挡或对象越界。
- 六个投资亮点图标大小统一、边距一致、语义对应。
- 行业概览左侧视觉填充均衡，不削弱右侧图表的主信息。
- PowerPoint 文件保持可编辑，母版、图表和原有内容结构不被破坏。
- 逐页渲染并在完整尺寸下检查；原文件保持不变。
