# 资本市场周报图表设计说明

## 目标

根据四份截至 2026-07-20 交付的市场数据工作簿，补齐 `资本市场周报_20260717_完整版_含WeekAhead.tex` 中的 22 个图表或小表占位，保持既有页面网格、文字内容和报告配色，并生成可由 XeLaTeX 编译的正式版本。

## 已确认原则

- 仅使用用户提供的四份工作簿，不联网补充数据。
- 数据集中缺少的 VIX、南向资金、回购、成交额、恒生国企指数、原油期限结构和美国实际利率，使用现有数据中最接近的指标替代。
- 图形输出使用矢量 PDF；TeX 通过 `\includegraphics` 引用。
- 沿用报告的财通蓝、金色、灰色体系；正收益为绿色，负收益为红色。
- 大图以排序横向条形图为主，小图使用对比柱状图、收益率曲线、分组条形图或紧凑指标表。
- 百分比保留两位小数，利率及利差变动以 bp 表示；最近值与周度基准日期沿用工作簿口径。

说明：TeX 中共 22 个占位（6 个大图占位、16 个小图或小表占位），设计映射与 22 个最终替换项一一对应。

## 文件与 TeX 结构

- 在 TeX 文件同目录建立独立图表资源目录，采用稳定英文文件名。
- 生成一个新的完整 TeX 文件，保留原文件不覆盖。
- 将每个 `\placeholder` / `\smallplaceholder` 定点替换为相同高度约束下的 `\includegraphics` 或紧凑表格。
- 图内不重复 TeX 已有的长标题，只保留必要的单位、图例、数值标签和替代口径脚注。

## 数据与错误处理

- 只使用 `qc_flag=OK` 的数据行。
- 缺失值保持空白，不补零、不推算。
- 同一图中的类别数、系列数和日期口径在生成前校验。
- 混合单位不放在同一数轴；百分比、收益率水平和 bp 变化分别展示。
- 若中文字体不可用，使用 TeX 已配置的 Noto CJK 字体路径或系统可用的同族字体。

## 验收标准

- 22 处占位全部被真实图表或指标表替换。
- 关键图表数值与工作簿逐项抽查一致。
- 图中文字在 A4 正常缩放下可读，无裁切、重叠或空白图。
- XeLaTeX 编译成功，无缺图错误。
- 渲染后的 PDF 逐页检查，页面数量与既有结构基本保持一致；如图表替换引发分页变化，则调整图形边距或高度而不删减正文。
