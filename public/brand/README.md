# psw identity

The lowercase name means **people spaces wellbeing**. Three connected figures also read
as open doorways: people belong in spaces that support everyday life.

- `psw-logo.svg`: primary forest logo with custom vector wordmark, transparent background.
- `psw-mark.svg`: symbol for compact placements, transparent background.
- `psw-logo-white.svg`: reversed logo for a dark background, transparent background.
- `psw-logo.png`: transparent high-resolution export for documents.

Leave clear space around the artwork equal to one head diameter. Preserve the proportions.
Use the full logo at 100 px wide or larger, and the mark at 24 px or larger. The application
favicon has its own padded dark tile at `app/icon.svg`. Artwork contains no external font,
script, link, or image. Keep the supplied accessible product name when embedding an image;
the shared inline UI component carries that name, and navigation links label their destination.
