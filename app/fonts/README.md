# psw fonts

Self-hosted fonts from the psw design system. Both are licensed under the SIL Open Font License 1.1.

| File | Font | Used for | License |
| --- | --- | --- | --- |
| `psw-rounded-bold.woff2` | 资源圆体 Resource Han Rounded CN Bold, subset to GB2312 level 1 | Titles and buttons in the app (`font-rounded`; serves every bold weight) | `OFL-ResourceHanRounded.txt` |
| `psw-rounded-heavy.woff2` | 资源圆体 Resource Han Rounded CN Heavy, same subset | Covers and big slogans only (`font-slogan`) | `OFL-ResourceHanRounded.txt` |
| `nunito-variable.woff2` | Nunito variable (200–1000), Latin | Prices, dates and other numbers (`font-display`, `font-num`) | `OFL-Nunito.txt` |

Body text and trust details use the system sans (PingFang SC / Microsoft YaHei / Noto Sans SC).
Characters outside the rounded subset fall back to the system sans.
